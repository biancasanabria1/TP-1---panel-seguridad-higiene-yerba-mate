# TP-1---panel-seguridad-higiene-yerba-mate
Panel web sobre siniestralidad, prevención y marco normativo en la agroindustria yerbatera de Misiones (2021-2025). Desarrollado con asistencia de Perplexity, Claude y Gemini Notebook, y alojado en Netlify.

## Herramientas e Inteligencias Artificiales Utilizadas

El desarrollo de este trabajo integró un flujo de trabajo asistido por IA para la investigación, estructuración de datos, redacción y codificación web:

1. **Perplexity AI:**
   * Utilizado para la investigación inicial y la recopilación de normativa oficial argentina (Ley N° 19.587, Ley N° 24.557, Decreto N° 617/97, Res. SRT N° 295/03) y antecedentes sectoriales sobre el peso de raídos, nivel de ruido y material particulado en molinos y secaderos.

2. **Gemini Notebook:**
   * Utilizado como cuaderno de estudio y base de conocimiento para sintetizar la información técnica, organizar los datasets simulados con fines académicos (`Siniestralidad_Yerba_Mate_Misiones_2021-2025.xlsx` e `Inversion_Prevencion_EPP_Yerba_Mate_Misiones_2021-2025.xlsx`) y extraer las conclusiones clave por etapa productiva.

3. **Claude:**
   * Encargado del desarrollo del código fuente web. Generó la estructura HTML semántica, para la renderización de todos los gráficos interactivos, tablas dinámicas y proyecciones lineales (2026-2027).

4. **Netlify:**
   * Plataforma seleccionada para el despliegue e integración continua, permitiendo la publicación y disponibilidad del sitio web interactivo en línea.
